# シフト自動作成ツール 要件メモ

放課後等デイサービスの月間シフトを、ルールを守りながら自動で作るツールの要件をまとめたメモです。
壁打ちで決まったことを随時書き足していきます。

## 1. 背景と目的

- 管理者が毎月、約14人分のシフトを作っている
- 今は、職員が紙に書いた希望休をAIに渡して1ヶ月分を作ってもらっている
- 配置基準や加算の条件が多く、手作業でもAI任せでも抜けや間違いが起きやすい
- **目的**：ルールを必ず守ったシフト案を自動で作り、管理者は確認と微調整だけで済むようにする

## 2. 基本方針

| 担当 | 役割 |
|---|---|
| 自動作成エンジン（プログラム） | ルールを必ず守ったシフトを計算する。守れない日があれば理由を出す |
| AI（MCPでつなぐ・任意） | 紙の希望休の読み取り、言葉での修正（例：「Aさんの休みを15日に」）、結果の説明 |
| 管理者 | 最終確認と微調整 |

- 入力が簡単にできるならMCPはなくてもよい。入力が複雑になる場合はMCPでAIから操作できるようにする

### 段階
1. 職員とルールを登録し、希望休を入れると1ヶ月分のシフトが出る（手入力で使える状態）
2. MCPでAIとつなぐ（紙の写真から希望休を入力、言葉で修正）
3. （必要なら）職員がスマホで希望休を出せるようにする

## 3. 絶対に守るルール

- 日曜日は全員休み
- 月〜土のうち、各職員は週に1日の週休を取る
- 希望休を反映する
- 毎日、**管理者または児童発達支援管理責任者**のどちらかが出勤している
  - 管理者は集計業務があるため、いない日があってもよい。その日は児発管が代わりになる
- 子どもの人数に応じて、必要な職種・人数を満たす（数字は宿題A）
- 専門的支援が必要な日は、専門職が出勤している
  - 専門職：理学療法士、作業療法士、言語聴覚士、心理士、児童指導員、保育士（経験5年以上）
  - 必要な日は月ごとに変わる

## 4. 勤務の種類

- 開始時間は 8:30 / 9:00 / 9:30 / 10:00 の4パターン
- どの時間に何人必要かは教室ごとに違う（詳細は未定）

## 5. 毎月入力するもの

- 営業日カレンダー（祝日は営業する日と休みの日がある）
- 専門的支援が必要な日
- 長期休み（夏休みなど）の期間：子どもの人数や来る時間帯が変わる
- 日ごとの子どもの人数（後述の課題あり）
- 職員の希望休

## 6. 最初に1回登録するもの

- 職員リスト：名前、職種・資格、経験年数、所属教室、可能な勤務時間
- 勤務パターン（開始時間）
- 「子どもの人数 → 必要な職員数・職種」の表

## 7. 外部ツール

- 利用予定は **HUG（ハグ）** で管理している
- 子どもの人数は保護者の連絡で日々変わるが、各児童の月の利用日数は毎月決まっている

## 8. 宿題（管理者が確認すること）

- [ ] **A. 人員配置の数字**：子どもの人数ごとに必要な職員数と職種（例：9人以下なら児童指導員2人、11人以上なら3人…は仮の数字）
- [ ] **B. 専門職の扱い**：専門職として入った人を、その日の基本の人数にも数えてよいか（加算の種類によっては別枠で置く必要がある）
- [ ] **C. 児童指導員の経験年数**：専門職として数えるのに「5年以上」の条件があるか

## 9. 保留中

- できれば守りたいルール（出勤日数の公平さ、連勤の上限、組み合わせの希望など）

## 10. 未確認の事項

- 教室はいくつあるか。職員は教室をまたいで勤務するか
- 定員は何人か。毎日「定員分の子どもが来る前提」で人数を組んでよいか
- HUGから利用予定をCSVやExcelで出力できるか
- 教室ごとの開始時間のルール（どんな日に何時からの人が何人必要か）
