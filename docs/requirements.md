# シフト自動作成ツール 要件メモ

放課後等デイサービスの月間シフトを、ルールを守りながら自動で作るツールの要件をまとめたメモです。
壁打ちで決まったことを随時書き足していきます。

## 1. 背景と目的

- 管理者が毎月、約14人分のシフトを作っている
- 今は、職員が紙に書いた希望休をAIに渡して1ヶ月分を作ってもらっている
- 配置基準や加算の条件が多く、手作業でもAI任せでも抜けや間違いが起きやすい
- **目的**：ルールを必ず守ったシフト案を自動で作り、管理者は確認と微調整だけで済むようにする

## 2. 基本方針

| 担当 | 役割 |
|---|---|
| 自動作成エンジン（プログラム） | ルールを必ず守ったシフトを計算する。守れない日があれば理由を出す |
| AI（MCPでつなぐ・任意） | 紙の希望休の読み取り、言葉での修正（例：「Aさんの休みを15日に」）、結果の説明 |
| 管理者 | 最終確認と微調整 |

- 入力が簡単にできるならMCPはなくてもよい。入力が複雑になる場合はMCPでAIから操作できるようにする

### 段階
1. 職員とルールを登録し、希望休を入れると1ヶ月分のシフトが出る（手入力で使える状態）
2. MCPでAIとつなぐ（紙の写真から希望休を入力、言葉で修正）
3. （必要なら）職員がスマホで希望休を出せるようにする

## 3. 絶対に守るルール

- 日曜日は全員休み
- 月〜土のうち、各職員は週に1日の週休を取る
- 希望休を反映する
- 毎日、**管理者または児童発達支援管理責任者**のどちらかが出勤している
  - 管理者は集計業務があるため、いない日があってもよい。その日は児発管が代わりになる
- 単位ごとに、児童指導員・保育士の人数基準を満たす（詳しくは「3-1. 人員配置基準」）
- 専門的支援が必要な日は、専門職が出勤している
  - 専門職：理学療法士、作業療法士、言語聴覚士、心理担当職員、保育士・児童指導員（経験5年以上）
  - 必要な日は月ごとに変わる

### 3-1. 人員配置基準（Webで調べた国の基準。自治体の最新資料での確認が必要）

**単位**とは、同じ時間に一体的に支援を受ける子どものまとまり。子どもが多い日は単位1・単位2に分けて支援する。
人数の基準は**単位ごと**に満たす必要がある。

| その単位の子どもの数 | 児童指導員・保育士の必要数 |
|---|---|
| 10人まで | 2人以上 |
| 11〜15人 | 3人以上 |
| 16〜20人 | 4人以上 |

- 10人を超えると、5人増えるごと（端数も含む）に1人ずつ増える
- サービスを提供している時間中は、ずっとこの人数がいる必要がある
- 児童指導員・保育士のうち1人以上は常勤
- 機能訓練担当職員・看護職員も数に入れてよいが、半数以上は児童指導員・保育士であること
- 児童発達支援管理責任者は別に1人以上（上の人数には数えない）
- 複数の単位を同時に行う場合は、同時に行う単位の数だけ常勤の従業者が必要（児発管を除く）

### 3-2. 専門的支援の加算（令和6年度改定後）

| 加算 | 専門職の置き方 |
|---|---|
| 専門的支援体制加算 | 基準の人数とは**別に**、常勤換算で1人以上を加えて置く |
| 専門的支援実施加算 | 専門職がその日にいればよい（常勤換算の条件なし）。専門的支援実施計画に沿って支援する |

- 保育士・児童指導員を専門職として数えるのは、児童福祉事業の経験が5年以上の人だけ
- 経験年数の数え方は加算によって違う（専門的支援体制加算では特別支援学校などでの教育経験は含まない）
- 「月ごとに必要な日が変わる」のは、専門的支援実施加算の計画日と考えられる

## 4. 勤務の種類

- 開始時間は 8:30 / 9:00 / 9:30 / 10:00 の4パターン
- どの時間に何人必要かは教室ごとに違う。まずは1教室分のルールを登録する
- サービス提供時間中ずっと基準人数を満たす必要があるため、開始時間だけでなく終了時間も必要

## 5. 毎月入力するもの

- 営業日カレンダー（祝日は営業する日と休みの日がある）
- 専門的支援が必要な日
- 長期休み（夏休みなど）の期間：子どもの人数や来る時間帯が変わる
- 日ごとの子どもの人数（後述の課題あり）
- 職員の希望休

## 6. 最初に1回登録するもの

- 職員リスト：名前、職種・資格、経験年数、常勤／非常勤、可能な勤務時間
- 勤務パターン（開始時間）
- 「子どもの人数 → 必要な職員数・職種」の表

## 7. 外部ツール

- 利用予定は **HUG（ハグ）** で管理している
- 子どもの人数は保護者の連絡で日々変わるが、各児童の月の利用日数は毎月決まっている

## 8. 宿題（管理者が確認すること）

- [ ] **A. 人員配置の数字**：3-1の国の基準で合っているか、自治体独自のルールがないか
- [ ] **B. 取っている加算**：専門的支援体制加算と専門的支援実施加算のどちらを取っているか（両方か）。体制加算なら専門職は基準人数とは別枠になる
- [ ] **C. 児童指導員等加配加算**を取っているか（取っていれば、その分の人数も毎日必要になる）

## 9. 保留中

- 複数教室の対応（職員が教室をまたいで勤務するケース）。まずは1教室で作る

- できれば守りたいルール（出勤日数の公平さ、連勤の上限、組み合わせの希望など）

## 10. 未確認の事項

- 単位1・単位2はどう分けているか（同じ時間に2グループ並行か、時間帯で分けるか）。各単位の定員
- どんな日に2単位になるか（子どもの人数で決まるのか、曜日で決まっているのか）
- 各開始時間の終了時間（勤務時間の長さ）
- 定員は何人か。毎日「定員分の子どもが来る前提」で人数を組んでよいか
- HUGから利用予定をCSVやExcelで出力できるか
- 教室ごとの開始時間のルール（どんな日に何時からの人が何人必要か）
